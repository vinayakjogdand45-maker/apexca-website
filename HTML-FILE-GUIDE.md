## 🔧 Edit Your HTML File

### **Using Notepad (Windows):**
1. **Right-click** the HTML file
2. **Select "Open with"**
3. **Choose "Notepad"**
4. File opens in text editor
5. **Make your changes**
6. **Save** (Ctrl+S)
7. **Open in browser** to see changes

### **Using TextEdit (Mac):**
1. **Right-click** the HTML file
2. **Select "Open with"**
3. **Choose "TextEdit"**
4. **Format → Make Plain Text**
5. **Edit your content**
6. **Save** and close
7. **Open in browser** to see changes

### **Using VS Code (Professional):**
1. **Download VS Code** (free): https://code.visualstudio.com
2. **Open VS Code**
3. **Drag HTML file into VS Code**
